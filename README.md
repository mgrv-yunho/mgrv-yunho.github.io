# html-pages

정적 HTML 파일을 GitHub Pages로 배포하기 위한 private 레포지토리입니다.

## 배포 방식

- 소스: `main` 브랜치 / 루트(`/`)
- 진입점: `index.html`
- 게시 URL: https://mgrv-yunho.github.io/html-pages/

## 업데이트 방법

```bash
# 파일 수정 후
git add .
git commit -m "update site"
git push
```

푸시하면 GitHub Pages가 자동으로 다시 빌드/배포합니다.

> ⚠️ private 레포에서 Pages를 실제로 게시하려면 GitHub Pro/Team/Enterprise 플랜이 필요합니다.
